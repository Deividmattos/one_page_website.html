# One-Page Website

A beginner-friendly one-page website built with HTML and CSS.

## Project files
- `one_page_website.html` — page structure and content
- `style.css` — page layout, colours, typography and responsive styling

## HTML requirements included
1. Home section with headings and paragraphs
2. Pictures section with two `<img>` elements
3. Contact form with `<form>`, `<input>`, `<textarea>` and a submit button
4. Video section with an embedded `<iframe>`
5. Footer with copyright and a back-to-top link
6. Navigation menu using HTML bookmarks (`href="#section"` and matching section IDs)

## How to view
Open `one_page_website.html` in a web browser. Keep `style.css` in the same folder so the styling loads.

The images and embedded video are loaded from external websites, so an internet connection is needed to display them.

The contact form is a front-end example only. It needs a server or form service to send messages.
